## Program Overview

{{ORGANIZATION}} welcomes vulnerability reports from security researchers as part of our bug bounty program.

## Scope

### In-Scope Assets

- Web applications: *.{{CONTACT_EMAIL | split "@" | index 1}}
- Mobile applications
- API endpoints
- Physical offices (with prior approval)

### Out-of-Scope Assets

- Third-party services
- Physical social engineering
- Denial of service attacks
- Spam or social engineering

## Vulnerability Types

### High Priority
- Remote code execution
- SQL injection
- Authentication bypass
- Sensitive data exposure

### Medium Priority
- Cross-site scripting (XSS)
- Cross-site request forgery (CSRF)
- Insecure direct object references

### Low Priority
- Missing security headers
- Information disclosure
- Configuration issues

## Rewards

### Reward Ranges

- **Critical**: $1,000 - $5,000
- **High**: $500 - $2,000
- **Medium**: $100 - $1,000
- **Low**: $50 - $500

### Reward Determination

- Impact on users and data
- Exploitation difficulty
- Quality of the report
- First-to-report priority

## Submission Guidelines

### How to Submit

Send detailed reports to: {{CONTACT_EMAIL}}

### Report Requirements

- Clear description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Proof of concept (if applicable)

## Rules of Engagement

### What We Expect

- Follow responsible disclosure
- Don't damage data or systems
- Respect user privacy
- Don't exploit beyond proof of concept

### What We Promise

- We'll respond within 48 hours
- We'll keep you updated on progress
- We'll work with you on disclosure
- We'll fairly reward valid findings
