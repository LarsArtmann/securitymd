# Security Policy

## Supported Versions

We support the following versions:

- Latest version: v2.x
- Previous version: v1.x

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to us privately before disclosing it publicly.

### How to Report

- Email: security@lars.software
- Response time: Within 48 hours

### Security Policy

- We investigate all reported vulnerabilities
- We provide patches within 90 days of disclosure
- We coordinate disclosure with researchers
- We maintain a security hall of fame

## Security Practices

### Development

- All code is reviewed before merging
- Dependencies are scanned regularly
- Security tests are run on every commit

### Infrastructure

- All services use TLS encryption
- Access is limited to authorized personnel
- Regular security audits are conducted

## Supported Versions

Only the latest major version receives security updates.

## Acknowledgments

We thank all security researchers who help us keep our users safe.
